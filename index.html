WCAG 2.2 accessibility checker with a fix list

Paste a page's HTML. A11yCheck runs the 70 WCAG-tagged rules in axe-core 4.14.1 (of 105 rules total) and lists every failing element, worst impact first, with how to fix it.

Your HTML renders in a sandboxed frame (scripts isolated from this page; nothing uploaded). Relative images and stylesheets may not load, so color-contrast results on pasted snippets can be incomplete.

A11yCheck runs the open-source axe-core 4.14.1 engine (MPL-2.0, Deque Systems) on HTML you paste, inside a sandboxed frame in your browser. Automated rules catch only part of WCAG; manual testing is still needed.
